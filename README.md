# Vínculos: el juego del amor

Juego interactivo de clasificación estilo trivia para CORE II (Universidad de La Sabana, 2026).

A cada participante se le presenta una pareja famosa de la ficción y debe decidir si representa el **amor líquido** o el **amor sólido**. Si acierta, gana un punto; si no, ve la respuesta correcta. En los dos casos aparece la justificación basada en los conceptos de Zygmunt Bauman trabajados en clase (Velásquez, 2020).

## Cómo jugar

- Abre `index.html` en el navegador (o la página de GitHub Pages del repositorio).
- Elige **Individual** o **Dos equipos por turnos**.
- Responde con los botones o con las teclas **L** (líquido) y **S** (sólido).
- Al final hay un repaso de las 12 parejas y preguntas para conversar en grupo.

## Archivos

| Archivo | Qué contiene |
| --- | --- |
| `index.html` | Estructura de las pantallas: inicio, juego y resultados |
| `styles.css` | Diseño visual |
| `game.js` | Lógica del juego: turnos, puntaje y retroalimentación |
| `data.js` | Las parejas, su clasificación y la justificación de cada una |

Para agregar o cambiar parejas, solo hay que editar `data.js`.
